固定资产管理系统 · 网络版　部署使用说明

数据集中存储 · 全公司同一本账 · 账号登录与角色权限 · 单文件服务器，零第三方依赖

1这套系统里有什么

文件作用放在哪里
ams_server.py服务器程序（Python 单文件，只用到系统自带功能，无需安装任何库）服务器/主机电脑
python-3.12.10-amd64.exePython 官方安装包（Python Software Foundation 数字签名已验证）与服务器同目录
一键安装Python.bat双击自动安装 Python 并配置环境变量；已装过则自动跳过与服务器同目录
资产管理系统_网络版.html系统页面（已内嵌二维码图片识别组件，离线可用，无需联网下载）与服务器同目录
ams_data.db数据库文件（首次启动自动创建，全部业务数据都在这一个文件里）自动生成，与服务器同目录
重置管理员密码.py忘记管理员密码时的应急重置工具与服务器同目录（用不到可不管）
资产管理系统.html原来的单机版（不需要网络共享时继续用它，两版数据相互独立）保持原位

2五分钟部署（在一台常开的电脑上）

1
拷贝整个文件夹把「资产管理系统_网络版」整个文件夹拷到主机电脑（例如 D:\资产系统）。文件夹内已自带 Python 官方安装包，无需提前准备任何环境。
2
安装 Python（双击即可）双击「一键安装Python.bat」：自动安装官方 Python 3.12.10 并配置好环境变量（仅当前用户，无需管理员权限，无需联网）。若本机已装过 Python 会自动跳过。也可手动双击 python-3.12.10-amd64.exe 安装（务必勾选 Add python.exe to PATH）。
3
启动服务器双击「启动资产系统服务器.bat」；或在文件夹里打开命令行（地址栏输入 cmd 回车）执行： 
python ams_server.py
启动成功会显示访问地址，并自动打开浏览器。首次启动自动创建数据库和管理员账号。
4
登录并修改密码默认账号 admin / admin123。登录后进入"系统设置 → 当前账号"点击"修改密码"。
5
创建同事账号并分发给全公司"系统设置 → 用户管理"中新增账号（建议每类岗位建 1-2 个），然后把访问地址告诉同事：同事在任何电脑浏览器打开 http://主机IP:8300 即可使用。
主机电脑的局域网 IP 启动时会自动显示（形如 http://192.168.x.x:8300）。建议在路由器/网管处为这台电脑设置固定 IP，地址就不会变。

3账号与角色权限

角色能做什么适合谁
管理员全部业务操作，含 领用审批（通过 / 驳回）、转移申请审核、出库发放、离职退回与点收入库（管理员专有）、用户管理、载入演示数据 / 清空数据 / 导入备份资产管理负责人（1-2 人）
用户入库登记、领用申请、提交转移申请（待管理员审核）、盘点、编辑台账、部门与分类维护、导出备份；不能审批、驳回与发放资产，不能办理离职退回（相关按钮不可见，接口层也拦截）日常操作系统的同事

旧版的"系统管理员 / 资产管理员 / 只读账号"升级后自动归入对应新角色：系统管理员→管理员，资产管理员与只读账号→用户。所有操作记录中的"经办人"自动取当前登录人姓名；退出登录请点右上角"退出"。

3+扫码与二维码说明（本轮新增）

  • 领用人限定注册用户：领用申请的领用人改为下拉选择，只能从系统注册用户中选取（账号在"用户管理"中创建）；流程调整为先勾选闲置资产、再填写领用信息——未勾选资产时领用信息表单置灰不可填，勾选后自动解锁。勾选支持点击复选框或整行任意位置，实时高亮并统计已选台数。
  • 图片识别二维码：入库登记、离职退回、盘点管理三处扫码框旁新增「图片识别」按钮——拍好照片 / 保存的二维码图片，点击按钮选图即可自动识别，识别结果自动提取资产编号并回填，扫码枪不在手边时同样能完成扫码。
  • 出库码＝通用信息码（不限网络）：码内为单行精简文本（名称 / 编号 / 状态 / 领用人 / 领用部门 / 领取时间 / 存放），无需联网、不限网络，微信 / 任意 App / 手机相机扫码均可显示。下载的 PNG 标签同时印有完整信息文字（资产名、编号、状态、领用人、领取时间、存放地点），不看手机也能直接核验。转移 / 退回后信息变更，系统会提示重新打印。
  • 在线码＝动态链接码（需内网）：扫码打开信息页，信息随转移 / 退回自动更新、无需重打；由服务器自动嵌入内网地址，需与服务器同内网使用。两种码按需选用，信息码适合张贴，在线码适合内网动态查询。
  • 动态信息，无需重打：部门转移、离职退回后，同一张二维码扫出来的信息自动更新（旧值留档在系统内），不用重新打印张贴。
  • 注意：出库码（信息码）不限网络；在线码要求手机与服务器在同一内网。资产码（AMS|编号）与产品码保持原样，供扫码枪使用，图片识别同样兼容（扫描信息码 / 在线码 / 资产码均可自动提取编号）。

4数据安全与备份

  • 数据只存在主机电脑的一个文件里：ams_data.db。备份 = 复制这个文件（建议每周一次，复制到共享盘或网盘）。
  • 备份前最好先停止服务器（命令行窗口按 Ctrl+C），复制完再启动；或至少避开正有人保存数据的时间点。
  • 页面内的"导出备份（JSON）"仍然可用，适合单次留档或迁移；恢复用"导入备份"。
  • 防互相覆盖机制：两人同时保存时，后保存的人会收到"数据已被其他同事修改"提示并自动刷新为最新数据。日常多人错峰操作基本不会遇到。
清除主机电脑浏览器缓存不影响数据（数据不在浏览器里）；但删除 ams_data.db 文件 = 删除全部业务数据，请谨慎。

5常见问题

同事打不开 http://主机IP:8300？

  • 确认主机电脑开着、服务器命令行窗口没关；
  • 首次启动 Windows 防火墙可能弹窗，请选择"允许访问"；若已错过，可在"Windows 安全中心 → 防火墙 → 允许应用通过防火墙"里勾选 Python；
  • 确认同事电脑与主机在同一内网（同一办公网段）。

提示"端口 8300 已被占用"？

用记事本打开 ams_server.py，把顶部 PORT = 8300 改成其他数字（如 8301）保存后重启。

忘记 admin 密码？

在服务器目录执行：python 重置管理员密码.py，密码会重置为 admin123，登录后再修改。

想开机自动启动服务器？

按 Win+R 输入 shell:startup 回车，把"启动服务器"用的快捷方式放进去；或交给公司 IT 做成 Windows 服务。

数据和单机版互通吗？

不互通，两版是独立存储。如需把单机版现有数据迁到网络版：在单机版"导出备份（JSON）"→ 网络版 admin 登录后"导入备份"即可，资产、单据、盘点、部门分类全部带过去。

6功能一览（与单机版一致）

数据看板：资产总数 / 在用占比 / 待办提醒 / 科室分布 / 盘点完成率 / 最近动态
资产业务：入库登记（入库部门必填）→ 领用申请 → 管理员审批 → 出库发放（出库二维码）；部门转移：用户提交申请 → 管理员审核生效（码随人走、旧值留档）；离职退回与点收入库：管理员专有（扫码核销、人走账清）
盘点：创建盘点计划 → 扫码枪 / 手输编号逐台登记 → 差异清单 → 导出差异
二维码中心：出库码（微信扫码可看的链接码，含领用人 / 领用部门 / 领取时间）/ 资产码 / 产品码三视图，下载 PNG 打印张贴
报表中心：台账、入库明细、出库发放、转移与退回、盘点差异、部门汇总六类报表，支持导出 CSV 与打印
